# trpo-pr04-Kinakh
# Описание П.Р.

Практическая работа №4. PHP: основы языка, запросы и обработка HTML-форм.

Небольшое PHP-приложение без фреймворков. На странице есть форма регистрации сотрудника с серверной проверкой данных и таблица сотрудников, которая читается из файла `dataset/employees.csv`. Таблицу можно фильтровать по отделу.

## Запуск

В папке проекта выполнить команду:


php -S localhost:8000 -t public


Затем открыть в браузере http://localhost:8000

## Структура проекта

- `public/index.php` - страница: форма, фильтр и таблица
- `src/functions.php` - функции: чтение CSV, проверка данных формы, получение списка отделов, экранирование вывода
- `dataset/employees.csv` - список сотрудников
- `dataset/form_cases.json` - тестовые случаи для проверки формы
- `README.md` - описание проекта

## Как проверить работу

1. Открыть страницу (ввод " php -S localhost:8000 -t public " в терминал). В таблице видны все сотрудники из `employees.csv`.
2. Выберите отдел в списке и нажмите «Показать». В таблице остаются только сотрудники этого отдела. Если выбрать «Все отделы», снова видны все.
3. Отправьте форму с пустым именем. Под полем появляется ошибка, остальные введённые значения остаются в форме.
4. Введите стаж `-2` или `60`. Появляется ошибка про стаж (допустимо целое число от 0 до 50).
5. Введите в имя `<b>test</b>`. Форма выдаёт ошибку, а в поле значение остаётся обычным текстом, а не жирным шрифтом.
6. Введите корректные данные: имя «Иван», отдел «Бухгалтерия», стаж 4, email `a@b.ru`. Ошибок нет, появляется сообщение «Данные корректны».

## Чем отличаются GET и POST

- **GET** передаёт данные в адресе страницы, например `?department=Разработка`. Их видно в строке браузера, страницу с такими параметрами можно сохранить в закладки. В проекте GET используется для фильтра по отделу.
- **POST** передаёт данные в теле запроса, в адресе их не видно. Подходит для форм с личными данными. В проекте POST используется для формы регистрации.

## Зачем нужен htmlspecialchars

Функция заменяет специальные символы на безопасные коды. Благодаря этому всё, что ввёл пользователь, выводится на странице как обычный текст, а не исполняется как HTML-тег. Т.е. строка `<b>test</b>` будет показана буквально, а не станет жирным текстом. В проекте для этого есть функция `e()` в `src/functions.php`, которая применяется ко всем выводимым значениям.

## Путь данных от формы до HTML

1. Пользователь заполняет форму и нажимает «Отправить». Браузер отправляет POST-запрос.
2. PHP получает значения из `$_POST` (с оператором `??`, чтобы не было предупреждений).
3. Строки очищаются от пробелов через `trim`.
4. Функция `validateInput` проверяет обязательность, длину и допустимые значения. Ошибки сохраняются в массив.
5. Если ошибки есть, они выводятся под полями, а введённые значения подставляются обратно в форму.
6. Любое значение, которое выводится в HTML, проходит через `htmlspecialchars` (функция `e()`).
